# TraderApp releases

Official Windows x64 builds by Kaldarbek Berik Muratuly.

Download the latest ZIP from Releases, extract the complete archive and open win-unpacked/TraderApp.exe. Starting with 0.6.30, use Settings → Updates to check, download and install future versions.

Update packages are authenticated with a pinned Ed25519 author key and SHA256. This does not replace a Windows Authenticode certificate. Application and database backups are retained locally.

Only release artifacts are published here. Source code, account databases, API keys and private signing keys are not included.
